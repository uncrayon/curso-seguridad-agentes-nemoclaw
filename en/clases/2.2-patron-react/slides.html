From a single call to the agent loop

  • An agent is a loop: observe → decide → act → stop?
  • The decide function can be code, search or an LLM; the loop doesn't change
  • Memory is the messages list you resend on every call

ReAct stands for Reasoning + Acting.

Pattern from Yao et al., 2022; it's behind LangChain, OpenClaw and almost every modern agent. Click 1: the question. Click 2: the reason → act → observe cycle (it lights up step by step on its own). Click 3: once it can, it answers. Click 4: the detective comparison.

The model runs nothing: it only asks. Your code is what runs it.

Click 1: the model only sees the tool's card (name, description, inputs = the schema). Click 2: it sends a request (tool_call) and your code checks it. Click 3: your code runs the tool. Click 4: the result comes back as text. Click 5: the model runs nothing. Stress it: the harness is what executes. That will be key for security later on.
